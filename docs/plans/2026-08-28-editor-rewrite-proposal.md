> 日期：2026-08-28 ｜ 状态：✅ 已确认并实施（方案 A + Markdown 增强 + 全量落地） ｜ 关联：docs/plans/2026-08-28-full-rewrite-design.md

## 1. 现状与痛点

当前书写页（EditorView）是重构一期的产物，功能完整但仍有明显提升空间：

| 维度 | 现状 | 问题 |
|---|---|---|
| 布局 | 单栏垂直堆叠（顶栏→标题→标签→工具栏→正文→状态栏） | 层级扁平，工具栏常驻占用纸面空间 |
| 沉浸感 | 顶栏 56px + 常驻工具栏，始终可见 | 无法"只面对纸面"，缺少专注模式 |
| 工具栏 | 常驻 5 组按钮（样式/标题/列表/插入/视图） | 对"写"干扰大；选中文字后才需要这些工具 |
| 目录 | 仅预览/分屏时内嵌，挤占正文宽度 | 长文阅读体验差 |
| 状态反馈 | 顶栏一行小字（自动保存中/已保存） | 不显眼，易错过保存状态 |
| 信息面板 | 无 | 创建/更新时间、字数等只能看底部一行 |

## 2. 设计方向（三案）

### 方案 A：沉浸式纸面书写（推荐 ⭐）

**理念：书写页 = 一张纸。打开即写，工具随叫随到。**

- **极简顶栏（44px）**：返回 ←｜类型徽标｜（右）保存状态点 + 保存 + ⋯更多菜单
- **纸面书写区**（居中 max 760px）：大标题（32px）→ 轻量标签行 → 无边框正文
- **浮动工具栏**：选中文字时在选区上方浮现（加粗/斜体/标题/链接/引用/代码），不选不出现 → 纸面零干扰
- **块级快捷**：行首输入 `# ` `- ` `1. ` `> ` `` ``` `` 自动进入对应格式（Typora 式，纯文本提示，不引入块渲染）
- **底部细状态栏（28px）**：hover/输入时显现 —— 字数 · 阅读时间 · 保存状态 · 目录 · 专注
- **专注模式 ⌘⇧F**：隐藏顶栏与状态栏，纸面全屏居中，Esc 退出；支持暗色纸面（晚间书写）
- **目录抽屉**：预览时从右侧滑出，不占正文宽度

### 方案 B：编辑工作台（侧栏 + 书写）

- 左侧 220px 信息侧栏：目录 / 笔记信息（创建·更新时间、标签、字数）/ 相关笔记
- 中区书写纸面 + 顶栏 + 底部状态栏（保留常驻工具栏）
- 适合**长文创作与整理**，但信息密度更高、不如 A 纯粹

### 方案 C：块级书写（Notion-like）

- 正文按"块"渲染（段落/标题/列表/引用），点击进入编辑、块可拖拽
- **风险提示**：需 Markdown ⇄ 块模型双向转换，属于编辑器内核级重写，工作量大、易引入数据兼容问题；与现有 Markdown 存储体系冲突点最多

## 3. 推荐方案 A 详细设计

### 3.1 页面结构

```
┌──────────────────────────────────────────────┐
│ ← 返回   类型[小记|文章]       ●已保存 保存 ⋯ │  ← 44px 极简顶栏
├──────────────────────────────────────────────┤
│                                              │
│           晨光里的第一杯茶                    │  ← 32px 大标题（自动生长）
│         [生活] [随笔] + 输入标签              │  ← 轻量标签行
│                                              │
│   窗外的光斜斜地落在桌上，茶叶在杯底缓缓舒展… │  ← 无边框正文（16px/1.9）
│   ▍                                        │  ← 光标处悬浮工具栏（选中时）
│                                              │
├──────────────────────────────────────────────┤
│   328 字 · 约 1 分钟     已保存于 16:28  ◇目录  ⛶专注  │  ← 28px 状态栏（hover 显现）
└──────────────────────────────────────────────┘
```

### 3.2 关键交互

| 交互 | 细节 |
|---|---|
| 浮动工具栏 | 选中文字 → 选区上方浮现（定位在选区中心，随选区移动）；含 加粗/斜体/划线/标题/H2/H3/引用/行内码/链接/代码块 |
| 块级快捷 | 行首输入 `#`+空格 → 标题样式提示；`-`/`1.` → 列表；`>` → 引用；`` ``` `` → 代码块（以轻量行内提示条呈现，不渲染块） |
| 保存反馈 | 双通道：顶栏小圆点（保存中=accent 呼吸点 / 已保存=绿色 / 未保存=琥珀点）+ 底部状态栏文字 |
| 专注模式 | ⌘⇧F 或 ⋯菜单进入：顶栏/状态栏淡出，纸面垂直居中，纸面宽度可调；Esc 退出 |
| 预览 | ⋯菜单或 ⌘P：全屏切换为阅读视图（MarkdownViewer），右侧可选目录抽屉 |
| 退出保护 | Esc：无未保存直接返回；有未保存 → 确认弹窗（保留） |
| 首次引导 | 创建模式首次聚焦正文时显示一行极淡提示"落笔，把此刻封存……"（现有文案） |

### 3.3 组件结构（完全重排）

```
views/EditorView.vue            → 编排：布局骨架 + 模式状态机 + 全局快捷键
components/editor/
├── EditorTopBar.vue            （极简顶栏：返回/类型/保存状态/⋯菜单）
├── EditorMoreMenu.vue          （⋯菜单：预览 / 专注 / 目录 / 信息 / 删除）
├── EditorPaper.vue             （纸面容器：留白节奏 + 聚焦态光环）
├── EditorTitle.vue             （32px 大标题，自动生长，accent 下划线）
├── EditorTags.vue              （轻量标签行 + 联想）
├── EditorBody.vue              （正文 textarea + 块级快捷提示 + 首行引导）
├── EditorFloatingToolbar.vue   （选区浮动工具栏）
├── EditorStatusBar.vue         （底部细状态栏）
├── EditorFocusMode.vue         （专注模式容器 + 暗色纸面）
├── EditorTocDrawer.vue         （目录抽屉）
└── MarkdownViewer.vue          （保留：阅读渲染 + 代码复制）
```

### 3.4 保留能力（全部不变）

自动保存 / 草稿恢复 / ⌘S / Esc 确认 / 字数·阅读时间 / 类型切换 / 标签管理 / 多语言 / 主题墨色 / 预览渲染（含代码高亮与复制）/ 目录跳转。

### 3.5 验收标准

1. 顶栏 44px、纸面居中、工具栏不选中不出现
2. 选中文字 → 浮动工具栏正确跟随并可用
3. ⌘⇧F 专注模式开关流畅，Esc 退出
4. ⌘P 全屏预览 + 目录抽屉
5. 保存状态双通道反馈准确（自动保存中/已保存/未保存）
6. vue-tsc / build / 测试全绿；桌面端功能回归通过

## 4. 待确认决策

1. **方案选择**：A（沉浸式，推荐）/ B（工作台）/ A+B 混合（沉浸式 + 可展开目录抽屉，实际即 A 的完整形态）
2. **正文编辑形态**：保持 Markdown textarea + 浮动工具栏（推荐，低风险）；或升级为"所见即所得"渲染层（中等风险）
3. **专注模式**：是否纳入首期（推荐纳入，是"沉浸感"的核心卖点）
